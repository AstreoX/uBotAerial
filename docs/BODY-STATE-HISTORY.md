# 固定物理步历史

开发版 Aerial 为其实际驱动的根组件提供 Core 的可选历史接口。需要与采用该接口的 Core、Sensor、ROS 一起重新编译。

消费者获取只读句柄后，Aerial 才开始记录；多个消费者共享一份缓冲，组件只保存弱句柄。释放最后一个消费者后，不再记录，也不保留该缓冲。

每个完成的物理步记录一次积分器状态。默认物理频率仍为 500 Hz，不新增线程，不改变飞行模型、固定步长或显示位姿外推。历史容量为 `2 * MaxStepsPerFrame + 2`，复用有界环形缓冲；改变容量配置时清空并重建。

查询连续区间时，向量字段线性插值，姿态使用归一化最短弧 SLERP。结果是固定步长状态的近似插值，不是额外执行一次物理积分。

重置、瞬移和被跳过的物理时间会清空历史；不会把跳步前的状态重新标记为跳步后的时间。碰撞冲量会分隔连续段，禁止跨该边界插值。EndPlay 或组件注销时，仍被消费者持有的历史视图立即失效；已结束或未注册的组件不能重新创建有效视图。

该能力不要求其他物理后端实现历史。没有历史能力的后端仍可供旧采样模式使用。
